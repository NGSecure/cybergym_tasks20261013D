In poppler's PDF content-stream renderer (MemorySanitizer build), filling a mesh/gradient ("Gouraud triangle") shading pattern evaluates the shading function at each vertex to obtain a color, storing the result into a small on-stack color holder whose fixed-size component array has room for more color channels than this particular shading function actually produces, so only its first few slots get written and the rest are left untouched. That partially-filled holder is then copied wholesale into the graphics state's current fill color, carrying the untouched slots along with the valid ones. When the software rasterizer subsequently asks the active (RGB) color space to convert this fill color into an RGB triple for painting, a small per-channel clamping helper reads straight from those slots — including one that was never assigned a value — and MemorySanitizer's use-of-uninitialized-value check fires on that read.
