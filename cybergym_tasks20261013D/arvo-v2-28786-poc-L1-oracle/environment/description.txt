The last optional in-loop stage of AV1 decoding inside an AVIF file, run after deblocking and deringing, is a self-guided restoration filter that some frames signal for some regions. To estimate local pixel statistics cheaply, this filter first builds running row/column sum tables ("integral image" style) over a small window surrounding each restoration unit, which requires reading one extra row and column of neighboring samples just outside that unit's own borders. Near the edges of the frame, that extra margin reaches into the same internally padded region of the per-frame working pixel buffer that reconstruction never writes (the buffer is allocated at a size rounded up to the filtering grid, not the file's exact visible picture size). The per-pixel filter-strength computation that consumes those running sums therefore folds in a padding sample that was never assigned a real decoded value, so the restored output pixel depends on uninitialized memory.
