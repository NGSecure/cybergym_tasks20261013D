After every block of an AV1-coded frame inside an AVIF file has been reconstructed, the decoder runs an in-loop directional deringing filter over the frame in small superblock-sized chunks. Immediately before filtering each chunk, the decoder first copies that chunk's just-reconstructed samples into a wider scratch buffer sized to give the direction-estimation math some working margin around the chunk's edges. For frame dimensions that are not an exact multiple of the superblock grid, part of that scratch margin lies outside the region the copy step actually fills, and is left holding whatever the scratch buffer happened to contain rather than a real decoded sample. The direction-estimation step that runs next scans bit patterns derived from sums taken across the whole scratch buffer, including that unfilled margin, so its result — which steers how strongly the deringing filter is applied — depends on bytes that were never given a real value.
