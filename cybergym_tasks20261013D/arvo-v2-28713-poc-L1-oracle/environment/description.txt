Decoding a still AVIF image whose embedded AV1 bitstream selects the lossless coding path (zero-quantizer) for at least one small luma block predicted with a directional (angular) intra mode: the directional predictor's edge-upsampling step fills a fixed-size stack reference array for the block's above/left neighbor row only up to however many neighboring samples are actually available at that position, leaving the remainder of that reference array with its original stack contents. When the following inverse transform used specifically for lossless blocks adds the prediction residual on top of this reference-derived value and the sum is range-limited to the coded bit depth before being written out, the range-limiting step reads from the still-unfilled tail of the reference array, so the reconstructed pixel's value silently depends on uninitialized stack memory rather than any bit actually present in the file.
