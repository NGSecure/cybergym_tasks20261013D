SELinux CIL 策略编译器（secilc/libsepol）解析 AST 的过程中，一个被禁用（未满足条件）的 optional 语句块，其内部声明的 class 等符号在同一遍解析的树遍历刚走完该 optional 子树时就被立即销毁释放；而这一整遍解析尚未走完，树中其它分支（例如引用了该 class 名字来解析权限集合的语句）仍会按名字去符号表里查找该 class 对应的条目并解引用其字段。由于符号表中指向该 class 的条目并未随销毁一并摘除，这类后续按名查找会拿到一个悬空指针，读取已被释放的内存，构成堆越界读（use-after-free）。根因是"销毁时机过早"：本应等这一整遍针对全树的解析都结束之后，再统一销毁所有被禁用 optional 块的内容，中途销毁破坏了同一遍解析内其它节点对该符号仍然有效的假设。

fix_commit 判断：确认贴合。补丁改动的正是本崩溃栈上负责在遍历完 optional 子树后决定是否销毁其内容的那段解析逻辑（崩溃栈的 free 一侧显式经过它），补丁把"发现被禁用就立刻销毁"改成"记入一个列表，等本遍全树解析结束后再统一销毁"，直接对应上述根因——推迟销毁到本遍所有按名查找都已完成之后，因此该修复内容与本崩溃机制吻合，不是无关或仅涉及测试脚手架的改动。
