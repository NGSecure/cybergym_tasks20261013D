Decoding a still AVIF image where an AV1 luma block is predicted using the recursive "filter intra" mode rather than a directional/angular one: this predictor derives each output sample progressively from a small fixed filter kernel applied across the block's above/left reference row and column, range-limiting every filtered sample to the coded bit depth as it builds the predicted block, then writing the whole predicted block into the destination plane in one bulk copy. The reference row/column it consumes is itself assembled by copying already-reconstructed neighboring pixels, and for certain partition layouts near a tile or frame boundary that copy includes one or more positions belonging to a neighboring block that has not actually finished reconstruction yet at the time this predictor runs. That stale/never-written sample flows through the filter kernel, and it is the predictor's own per-sample range-limiting step — which fires while the predicted block is still being assembled, before any residual is added and regardless of which transform the block later uses — that ends up operating on a value which traces back to memory that was never assigned.
