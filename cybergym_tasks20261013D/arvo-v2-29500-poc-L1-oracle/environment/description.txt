matio's HDF5 v7.3 (.mat file) reader (AFL build under ASan): while gathering a dataset's own metadata, the reader opens that dataset's class-identifying attribute by name, which makes HDF5 decode the attribute's message inside the dataset's object header. When the object-header chunk holding that attribute description is crafted so the decoder derives a value size larger than the buffer HDF5 actually allocated to hold the decoded chunk data, the byte-copy that materializes the attribute's raw value into that heap buffer reads a few bytes past its end, producing a small heap-buffer-overflow read right at the buffer's boundary.
